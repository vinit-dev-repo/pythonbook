# 25c - Project - Modular Values and Operator Contracts

The code of the chapter **25c - Project - Modular Values and Operator Contracts** of the Python tutorial (folder `03 - Objects, protocols and testing`), copied byte for byte from the chapter. The chapter explains every line. Each table below says where a file sits in the chapter: the section heading and the line where the code starts, so you can read the explanation next to it.

## What this chapter teaches

- How to do arithmetic while keeping old aliases and dictionary keys unchanged
- Why mathematical congruence, object equality and exponent meaning need separate contracts
- How to preserve reflected dispatch and operand order while removing repeated code
- How to test each complete version when you build it, then compare all three
