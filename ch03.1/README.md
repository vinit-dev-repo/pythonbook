The code of the chapter **03.1 - Reading Your Python Version** of the Python tutorial (folder `01 - Orientation`), copied byte for byte from the chapter. The chapter explains every line. Each table below says where a file sits in the chapter: the section heading and the line where the code starts, so you can read the explanation next to it.

## About this chapter

Your version has three numbers, such as `3.15.0`. The first two numbers identify the language release used by this tutorial: Python 3.15. The final number is a maintenance release. Run the version command from [[Python Tutorial/01 - Orientation/02.1 - Getting Ready to Run Python|02.1 - Getting Ready to Run Python]] when you need to check your installation.
