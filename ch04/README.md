The chapter explains every line. Each table below says where a file sits in the chapter: the section heading and the line where the code starts, so you can read the explanation next to it.

## What this chapter teaches

- The basic kinds of data Python works with: numbers, text, and true/false values
- That *everything* in Python is an object, and what that word means
- What a variable really is (a name tag, not a box)
- The arithmetic operators, including the two "strange" ones: `//` and `%`
- The order Python does maths in (precedence)
- How to compare values, and how to combine comparisons with `and`, `or`, `not`
- What `=` really does, and how `print` separates and ends the values it shows
