The code of the chapter **33b - Project - Reuse a Finite Forwarding Interface** of the Python tutorial (folder `04 - Iteration and resource management`), copied byte for byte from the chapter. The chapter explains every line. Each table below says where a file sits in the chapter: the section heading and the line where the code starts, so you can read the explanation next to it.

## What this chapter teaches

- How explicit mixins, a small router, and descriptors reuse the same five forwarding operations
- When an operation is checked, when a direct form bypasses it, and which object is the bound receiver
- Why retrieving a descriptor operation differs from invoking the returned target-bound method
- Why a finite forwarding interface is neither universal proxying nor a security boundary
