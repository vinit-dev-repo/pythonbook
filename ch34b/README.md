# 34b - Project - Calling and Combining Random Containers

The code of the chapter **34b - Project - Calling and Combining Random Containers** of the Python tutorial (folder `04 - Iteration and resource management`), copied byte for byte from the chapter. The chapter explains every line. Each table below says where a file sits in the chapter: the section heading and the line where the code starts, so you can read the explanation next to it.

## What this chapter teaches

- Why removing a value is different from returning it from a callable
- How `+` and `+=` have different operand, result, identity, and failure policies
- How to reuse the accepted `Tombola` contract for two real extension classes
- Why random order, shallow snapshots, and partial generator failure limit what we can promise
