# 15.1 - Names, Types and Rebinding

The code of the chapter **15.1 - Names, Types and Rebinding** of the Python tutorial (folder `02 - Language and first tools`), copied byte for byte from the chapter. The chapter explains every line. Each table below says where a file sits in the chapter: the section heading and the line where the code starts, so you can read the explanation next to it.

## What this chapter teaches

- How to trace names and the objects they refer to without guessing about memory addresses
- That the type belongs to the object, not to the name
- What reassignment does, and what it leaves alone
