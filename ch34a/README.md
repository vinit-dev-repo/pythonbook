# 34a - Project - A Shared Contract for Random Draws

The code of the chapter **34a - Project - A Shared Contract for Random Draws** of the Python tutorial (folder `04 - Iteration and resource management`), copied byte for byte from the chapter. The chapter explains every line. Each table below says where a file sits in the chapter: the section heading and the line where the code starts, so you can read the explanation next to it.

## What this chapter teaches

- How an abstract base class defines a small random-draw contract
- How three classes can meet one contract while storing and reading data in different ways
- What ABC registration recognizes and what it does not implement
- How to test random draws without claiming a fixed order or statistical fairness
