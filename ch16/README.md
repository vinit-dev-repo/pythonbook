## What this chapter teaches

- How Python's number types represent values and combine in arithmetic
- Why Python integers have no fixed-width overflow, and how to write them in binary, octal and hex
- Why `0.1 + 0.2 != 0.3`, and how to choose exact equality or a tolerance for floats
- The difference between truncating, flooring, ceiling and rounding — and why `round(0.5)` is `0`
- `Decimal` for decimal representation and explicit rounding, and `Fraction` for exact ratios
- Why `True + True` is `2`, and the common built-in values that are falsy
- Handy tricks that lean on short-circuiting
