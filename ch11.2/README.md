# 11.2 - Working with Text Files

The code of the chapter **11.2 - Working with Text Files** of the Python tutorial (folder `02 - Language and first tools`), copied byte for byte from the chapter. The chapter explains every line. Each table below says where a file sits in the chapter: the section heading and the line where the code starts, so you can read the explanation next to it.

## What this chapter teaches

- How to open, read and write text files safely with `with`
- The difference between `"w"` and `"a"`, and why to name the encoding
- How to print to a file, and how read positions, bytes and update modes work
