# 02.2 - Running Your First Python Program

The code of the chapter **02.2 - Running Your First Python Program** of the Python tutorial (folder `01 - Orientation`), copied byte for byte from the chapter. The chapter explains every line. Each table below says where a file sits in the chapter: the section heading and the line where the code starts, so you can read the explanation next to it.

## What this chapter teaches

- How to create a folder and file in an editor, then save, run, edit, save, and rerun that file
- How to read and repair your first error message
- What the standard library is, with `math` as the first example
- The three ways to run Python: the REPL, script files, and notebooks
- How to open a terminal in your project folder on every operating system
- Useful flags that change how Python runs a file
