# 05 - Control Flow

The code of the chapter **05 - Control Flow** of the Python tutorial (folder `02 - Language and first tools`), copied byte for byte from the chapter. The chapter explains every line. Each table below says where a file sits in the chapter: the section heading and the line where the code starts, so you can read the explanation next to it.

## What this chapter teaches

- What "control flow" means, and why a program needs it
- Why indentation matters in Python (it is not just neatness)
- `if` / `elif` / `else` — making decisions
- The ternary expression — a mini `if` that fits on one line
- `range()`, and how `for` loops walk through things
- `while` loops, and the different ways a loop can end
- `break`, `continue`, and the loop `else` clause (this one confuses everyone at first)
- How to escape an infinite loop
- When to reach for `for` and when to reach for `while`
