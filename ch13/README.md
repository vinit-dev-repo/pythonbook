Each table below says where a file sits in the chapter: the section heading and the line where the code starts, so you can read the explanation next to it.

## What this chapter teaches

- How Python's `re` API applies the pattern language from the shared Regular Expressions module
- How to search text with `re.search`, `re.match` and `re.fullmatch`
- How Python spells and reads named groups
- How to find-and-replace with `re.sub` and split text with `re.split`
- The useful flags: `IGNORECASE`, `MULTILINE`, `DOTALL`, `VERBOSE`
- When to compile a reusable `Pattern` object
