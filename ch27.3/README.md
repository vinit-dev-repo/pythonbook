## What this chapter teaches

- Add behavior to a class with a decorator, and keep the class identity.
- Return the class, and see what a missing `return` binds to the name.
- Derive comparisons from one shared key, and use `functools.total_ordering` on a finished class.
- Return a replacement function for a class name, and keep the original class under another name.
