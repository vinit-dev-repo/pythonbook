## What this chapter teaches

- Say what a **protocol** is and how Python uses supported operations.
- Say what makes something a sequence.
- Show how `__len__` and `__getitem__` provide the main sequence operations.
- Tell mutable and immutable sequences apart, and name the extra methods that mutable ones need.
