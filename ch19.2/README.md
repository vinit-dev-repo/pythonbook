## What this chapter teaches

- `namedtuple`: giving each position in a tuple a real name
- How to read a field by name or by position, and why equality still compares values
- The record-editing tools: `_make`, `_asdict`, `_replace` and `_fields`
- Why a new outer record can still share a mutable field with the old one
