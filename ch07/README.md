## What this chapter teaches

- What a dictionary is, and why it is called an **associative array**
- How to create, read, add, update and delete entries in a dictionary
- Why dictionary keys must be **hashable**, in plain words
- How to loop over a dictionary's keys, values, and key-value pairs
- Real jobs dictionaries are good at: counting, lookup tables, records
- What a set is, how it differs from a list, and the `{}` empty-set trap
- Set operations: union, intersection, difference, symmetric difference
- A simple rule for choosing between list, tuple, dict and set
