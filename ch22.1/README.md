## What this chapter teaches

- What dunder methods are and which Python operations call them
- How `__str__` and `__repr__` give text for people and text for developers
- How `__bytes__` defines the binary form of an object
- How to make your own objects work with `+`, `-`, `*`, `==`, `<` and the other comparison operators
