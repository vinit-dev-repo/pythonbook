# 02 - Setting Up Your Python Workshop

The code of the chapter **02 - Setting Up Your Python Workshop** of the Python tutorial (folder `01 - Orientation`), copied byte for byte from the chapter. The chapter explains every line. Each table below says where a file sits in the chapter: the section heading and the line where the code starts, so you can read the explanation next to it.

## What this chapter teaches

- How to check whether Python is already installed, and how to install it on Windows, Mac and Linux if it is not
- How to open a terminal in your project folder on every operating system
- Just enough of the command line to survive: what a terminal is, moving between folders, running a script
- How to create a folder and file in an editor, then save, run, edit, save, and rerun that file
- The three ways to run Python: the REPL, script files, and notebooks
- The tools people use to write Python: VS Code, Anaconda, Google Colab, GitHub Codespaces
- What a virtual environment is, why you need one, and how to make and use one
- How to install packages with `pip`
- A full walkthrough that ties everything together
