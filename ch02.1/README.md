# 02.1 - Getting Ready to Run Python

The code of the chapter **02.1 - Getting Ready to Run Python** of the Python tutorial (folder `01 - Orientation`), copied byte for byte from the chapter. The chapter explains every line. Each table below says where a file sits in the chapter: the section heading and the line where the code starts, so you can read the explanation next to it.

## What this chapter teaches

- How to check whether Python is already installed, and how to install it on Windows, Mac and Linux if it is not
- Just enough of the command line to survive: what a terminal is, moving between folders, running a script
- The tools people use to write Python: VS Code, Anaconda, Google Colab, GitHub Codespaces
