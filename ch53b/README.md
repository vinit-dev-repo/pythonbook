## About this chapter

Prerequisite: Start this required inline visit after lesson 53 has installed `Flask` and introduced the application object, routes, templates, forms, redirects and JSON responses. Intended entry: Place `notes_app.py` beside a `templates` folder containing `notes.html`, run `python notes_app.py` from that folder, then open `http://127.0.0.1:5000` in your browser. The app uses local in-memory state, so notes reset when the server restarts. After this project, return to **Check the routes without starting a server**, then continue to **Connecting to a real database**.
