## What this chapter teaches

- When inheritance is the right tool, and when composition is better
- The four pillars of OOP in plain words: encapsulation, abstraction, inheritance and polymorphism
- How underscores and name mangling mark internal names
- How an abstract base class requires methods, and how duck typing needs no shared parent
