## What this chapter teaches

- What a higher-order function is, and how to inspect a function like any other object
- How `inspect.signature` and `bind` describe a call shape without running the body
- Where a function can keep state between calls: module, closure, function attribute, instance or saved default
- How `functools.reduce` folds a sequence into one value, and when a built-in is clearer
