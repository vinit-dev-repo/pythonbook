## What this chapter teaches

- What "control flow" means, and why a program needs it
- Why indentation matters in Python (it is not just neatness)
- `if` / `elif` / `else`: making decisions
- Which values count as true or false in a condition
- The ternary expression: a mini `if` that fits on one line
