## What this chapter teaches

- Why tests are useful and which problems they help you find
- What a test is, in plain words, and how `assert` replaces a manual check
- How to install pytest, name tests so that it finds them, and read a passing and a failing run
- How a collection error, a run with no tests and a failed assertion differ
