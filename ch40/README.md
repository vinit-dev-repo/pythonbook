# 40 - Sets in Depth

The code of the chapter **40 - Sets in Depth** of the Python tutorial (folder `06 - Containers and data boundaries`), copied byte for byte from the chapter. The chapter explains every line. Each table below says where a file sits in the chapter: the section heading and the line where the code starts, so you can read the explanation next to it.

## What this chapter teaches

- Basic set operations: membership, subset, union, intersection, and difference
- Why set membership is usually much faster than list membership
- How to create sets and how to write an empty set
- The operations you can call as methods vs the symbols you can use as operators
- How to update a set in place, and how copying a set works
- What a `frozenset` is and why you'd want one
- How dictionary views borrow set behaviour
- Useful patterns for removing duplicates, comparing lists, and finding missing items
