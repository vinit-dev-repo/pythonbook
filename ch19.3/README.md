The code of the chapter **19.3 - Defaults, Extending and Real Uses** of the Python tutorial (folder `02 - Language and first tools`), copied byte for byte from the chapter. The chapter explains every line. Each table below says where a file sits in the chapter: the section heading and the line where the code starts, so you can read the explanation next to it.

## What this chapter teaches

- How `defaults` fill the rightmost fields, and why a mutable default is shared
- How to give a record type your own docstring
- How to extend a record type by building a new one from the old field names
- How to return named results and fill a fixed record from a dictionary
