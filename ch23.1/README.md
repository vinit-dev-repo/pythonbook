## What this chapter teaches

- How a child class can reuse methods and class attributes from a parent class
- How overriding replaces a parent method, and how `isinstance` and `issubclass` ask about families of classes
- How inherited methods and class methods keep the child as their receiver
- How `super()` extends a parent method instead of replacing it
