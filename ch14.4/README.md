## What this chapter teaches

- Why two strings that look the same can compare unequal, and how normalisation fixes it
- Which standard-library APIs keep `str` or `bytes` as given, and how regex works on each
- How to compare text without caring about case, under an explicit policy
- How to look up a character's name, category and numeric value
