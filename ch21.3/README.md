## What this chapter teaches

- Why a class is callable, and why `int` is a class too
- How `type` and `isinstance` ask different questions
- How runtime attributes work, and why a typo becomes a new attribute
- How `vars`, `getattr`, `setattr` and `delattr` read and change an object's attributes
- How `staticmethod` and `FunctionType` show functions as class attributes
