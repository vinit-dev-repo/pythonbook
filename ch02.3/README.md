## About this chapter

Two projects may need different versions of the same package. For example, project A needs version 1 and project B needs version 2. If both projects use one shared package area, installing version 2 may stop project A from working. A **package** is a group of ready-made Python code. You can install a package and use its code in your project. This saves you from writing every part yourself.
