## What this chapter teaches

- How `groupby` handles consecutive equal keys, and why you sort first
- The four combinatorics tools: `product`, `permutations`, `combinations` and `combinations_with_replacement`
- How `pairwise` and `batched` make overlapping pairs and fixed-size tuples
- How far `islice`, `takewhile` and `groupby` read their input, including values they never yield
- How to pick the right tool for a task
