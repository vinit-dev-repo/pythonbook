## What this chapter teaches

- Trace names and shared references without guessing about memory addresses.
- Distinguish rebinding a name from mutating an object.
- Explain shallow copies, repeated rows, and argument sharing.
- Choose value equality (`==`) or identity (`is`) deliberately.
